Este projeto consiste no desenvolvimento de um mini site de roupas, criado com o objetivo de praticar e aprimorar meus conhecimentos em desenvolvimento web, com foco na estruturação de páginas HTML e na estilização com CSS.Durante o desenvolvimento, trabalhei na organização dos arquivos do projeto, na montagem das páginas e na navegação entre diferentes arquivos HTML.

Objetivos:Praticar a estruturação de páginas com HTML.
Desenvolver habilidades de estilização com CSS.
Trabalhar com cores, fontes, espaçamentos e organização dos elementos.
Praticar a montagem e a organização de páginas web.
Implementar a navegação e a transferência entre páginas HTML por meio de links.

Tecnologias utilizadas:
HTML5: estruturação das páginas.
CSS3: estilização e personalização visual do site.

Aprendizados:O desenvolvimento deste projeto contribuiu para o meu aprendizado sobre a criação de páginas web, a organização de arquivos, a aplicação de estilos com CSS e a navegação entre diferentes páginas de um mesmo site.
